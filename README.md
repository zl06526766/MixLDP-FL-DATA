# Public Benchmark Datasets Used in This Study

This repository provides the public dataset links used in the manuscript:

**MixLDP-FL: Layer-Wise Mixed Local Differential Privacy in Federated Learning**

No new datasets were created in this study. All datasets used in the experiments are publicly available.

## Datasets

1. MNIST  
   https://huggingface.co/datasets/ylecun/mnist

2. Fashion-MNIST  
   https://github.com/zalandoresearch/fashion-mnist

3. CIFAR-10  
   https://www.cs.toronto.edu/~kriz/cifar.html

## Data Availability Statement

The datasets used in this study are publicly available. MNIST is available at https://huggingface.co/datasets/ylecun/mnist, Fashion-MNIST is available at https://github.com/zalandoresearch/fashion-mnist, and CIFAR-10 is available at https://www.cs.toronto.edu/~kriz/cifar.html.
